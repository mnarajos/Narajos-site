# Poppins test fixtures

These Latin-subset WOFF2 files are used only by the GCSE SVG label geometry
checks, so that the same font metrics are tested even when the website's
Google Fonts request is unavailable. They are Poppins by the Poppins Project
Authors, distributed under the SIL Open Font License 1.1 in [OFL.txt](OFL.txt).

- `Poppins-600-latin.woff2`: Google Fonts Poppins 600 Latin, downloaded unchanged from <https://fonts.gstatic.com/s/poppins/v24/pxiByp8kv8JHgFVrLEj6Z1xlFQ.woff2>.
- `Poppins-700-latin.woff2`: Google Fonts Poppins 700 Latin, downloaded unchanged from <https://fonts.gstatic.com/s/poppins/v24/pxiByp8kv8JHgFVrLCz7Z1xlFQ.woff2>.
- Project and licence provenance: <https://github.com/itfoundry/Poppins> and <https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt>.

These fixtures do not change the site's font delivery. The audit also checks
the native rendering and a separate system fallback.
