# A-level catch-up: teaching-block visual audit

Working inventory, not a completion claim. Each row identifies the precise passage numbers in the concept's authored key array. Ordinary recap groups pair passages 1–2, 3–4, etc.; synapse uses its four authored group boundaries. Figures here are those displayed beside the block; concept-wide shared figures at the end or inside optional related diagrams are not counted as step-adjacent. Guided routes put these key blocks inside “Review key knowledge”; separate guided stages require further review.

Accuracy, teaching relevance and rendered readability are deliberately separate. “Checked, partial” means the figure explains only the named part of a passage group; other ideas remain open. “Pending” means no claim of review. A presence check cannot establish quality.
