# Narajos visual conventions

- Use the existing light styling on public pages and preserve the subject colours of the revision tools and simulations. Focused Questions follows the device colour preference for readability in class.
- Use one clear page heading and organise instructions into short steps. Aim for 16px or more for explanation text and 14px for supporting labels. Keep decorative captions and metadata subordinate.
- Use existing borders, card padding, and shared corner-radius tokens. Leave clear space between teaching, practice, and feedback.
- Use filled buttons for the main action and outlined buttons for secondary actions. Use text links for navigation or supplementary actions. Put labels beside the controls they describe.
- Mark selected choices with a clear state such as a checkmark, bolder text, or a labelled radio. Give keyboard focus its own visible outline. Pair feedback colour with words that state the outcome.
- Give disclosures concise labels and enough height to open by touch. Keep inline vocabulary controls in sentence flow. Use icons where they clarify an action, and mark decorative SVGs as hidden from assistive technology.
- Label diagrams and graphs clearly. Provide equivalent text or a data table when a visual alone would leave out useful information. Let wide diagrams scroll inside their own panel.
- Use the existing tokens in `public/assets/home-link.css` for shared controls, focus, and surfaces. Apply them gradually when editing a component.
