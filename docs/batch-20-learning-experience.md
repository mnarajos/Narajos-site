# Batch 20 learning experience

Baseline main 993ab269 contains Batch 19. Both site and browser workflows succeeded and no pull requests were outstanding. Existing diagnostic checks, teaching, hints and adaptive follow-ups remain available. The eight transfer tasks use a separate local record after lesson checks, including when pupils reopen a previously completed lesson.

Numerical responses use a labelled unit and compare the entered number. An error gives method feedback and flags subsequent success as supported. Written responses retain the first attempt alongside criteria, a model and an editable revision. Their self-review status never enters the objectively correct count. Saved multiple-choice sessions and existing identifiers retain their previous meaning.

## Revision session sample

The sample used the site's topic ordering and mixed-practice selector in Chromium. Topic runs covered cells, atoms and energy stores at both tiers. Six ten-item mixed runs drew from the corresponding papers, progressing from easy to medium to hard. These are simulated selection trajectories, not observations of pupil behaviour. In both tiers atoms began with three recognition tasks before calculations. The foundation biology mixed run began with three MCQs; Higher physics ended with four two-part items. The targeted change prefers another eligible format after two consecutive items of one format. The band, targeted follow-ups, fresh-item preference and within-topic teaching order remain intact. Repetition remains possible when the eligible pool requires it.

The A-level Exam Skills written route already preserved the original draft and had question-specific criteria. Its comparison stage now tells pupils how to use the criteria to revise a scientific link. Human Biology F170/F171 Quick Mix already builds from two warm-ups through core and applied tasks, penalises repeated formats and adapts later choices. Its selector was retained. Written review now connects the rating of the original response directly to an improvement in the revision box. The knowledge-only support for NEA units retains its limits.

## Verification and limitations

The catch-up suite exercises route opening, saved historical answers, wrong numeric input, reloading an unfinished response, supported numerical success, first-draft preservation, separate revisions and self-reviewed outcomes. Widths include 320, 390, 768 and 1280 pixels. Existing A-level, Human Biology, site and cross-browser checks run independently. The six written transfer tasks use short text, including ordered steps, so they need neither dragging nor automatic marking.

This release does not establish improved engagement or learning. An observed trial should check whether pupils notice and attempt the transfer task following the completion heading, whether younger pupils can comfortably type the short method, and whether pupils use the first-draft comparison to correct an explanation. A full manual journey audit of all A-level topic and Maths Skills sessions, and a manual screen-reader trial, remain outstanding.
