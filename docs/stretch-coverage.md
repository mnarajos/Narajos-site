# Stretch classification and coverage

Review baseline: main `93821b2`, including PR #87. This is a limited manual review of existing activities, not a complete inventory. Counts below are unique activities, not links. Counts do not measure quality; absence of an icon does not imply ordinary practice lacks challenge.

## Convention

Stretch is an additional, optional opportunity requiring particularly demanding independent application or reasoning. Core challenge is demanding practice expected in the normal sequence and does not get an icon. Recall, extra calculations, terminology, length, marks, an existing difficulty label, and beyond-specification enrichment alone do not qualify. Foundation activities must stay within Foundation assessable content; Higher-only content must not be made compulsory for Foundation. A-level tasks should support high attainment without restricting access or promising grades; OCR tasks should reflect its assessment rather than A-level essay conventions, and must not coach NEA submission.

For every proposed marker record qualification, paper/topic/unit, stable existing ID, destination, classification (optional Stretch or core challenge), reasoning type, evidence and review status. Inspect the actual task, its independence and its entry point. Only a reviewed optional Stretch entry receives the shared icon and visible label. Never change question IDs or progress keys to classify an activity. The SVG is decorative beside visible text; the label is part of the existing link or heading, not a separate control. Re-review when content or optionality changes.

The existing H flag and numerical Maths Skills Stretch ladder are not sufficient evidence. Skills Practice and other simulations remain unreviewed.

Priority for future review: establish whether A-level paper tasks can be offered as optional without altering the core sequence; review GCSE Chemistry and Physics and Foundation/Higher alignment; review OCR units beyond F171; then examine Catch-up, Skills Practice and simulations for specific independent optional tasks. These gaps are review and development priorities, not requests to add questions in this change.
