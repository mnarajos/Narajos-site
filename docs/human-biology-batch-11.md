## Before and after

- **F170 glucose feedback.** The worked sequence taught insulin, then asked about glucagon in independent practice. The new model distinguishes secretion from target-cell response. The independent task supplies a shivering scenario and asks pupils to show how the response opposes the initial temperature fall.
- **F171 screening results.** The original model covered the positive row and the guided task reused the same data. The revised example highlights each of the four cells. Guided and independent tasks use different tables. The independent task requires choosing the correct denominator to evaluate a claim.

## Learning flow, writing and visuals

Priority lessons link to the existing Build Understanding sequence and keep the existing topic practice and revision links. Feedback in related questions can open a relevant worked step, such as converting units or tracing a false positive. Return links preserve the active queue, retry, response and explanation. The new lessons use the existing teaching framework and practice stores.

The glucose lesson models a short cause–mechanism–consequence explanation. Treatment has a Single Paragraph Outline with a scientific claim, supporting mechanism and a qualified conclusion. Research evidence compares description, explanation, analysis and evaluation. Revised written tasks retain the original answer, criterion choices and an editable revision. The pupil explicitly finishes their review. These are learner judgements against authored criteria. Independent, supported, corrected and revealed objective outcomes remain distinct. Older answers to revised prompts stay in their earlier lesson records, and the new prompts start with an empty attempt. Question-bank and flashcard history retains its existing format.

The scale-bar image, the glucose and immunology pathways, and the screening, monitoring and research tables show which evidence is in use. Outlines, labels and explanatory text convey the focus. On narrow screens, the current reasoning step stays beside the evidence and a previous-step control is available. Worked examples and supported practice have a clear next action. The completed answer button is hidden and the learner can reopen the model.

## Verification and limits

- Scientific checks covered the worked arithmetic, scales and units, glucose and immune mechanisms, screening classifications, instruments and inference, and the limits of each fictional case. See the [OCR specification](https://www.ocr.org.uk/Images/697578-specification-cambridge-advanced-national-in-human-biology.pdf), [OpenStax microscopy](https://openstax.org/books/microbiology/pages/2-3-instruments-of-microscopy), [OpenStax homeostasis](https://openstax.org/books/biology/pages/33-3-homeostasis), [NHS screening](https://www.nhs.uk/tests-and-treatments/nhs-screening/), [NICE fracture guidance](https://www.nice.org.uk/guidance/ng38/chapter/recommendations) and [NHS Parkinson's treatment](https://www.nhs.uk/conditions/parkinsons-disease/treatment/).
- Automated checks cover all 44 guided routes. The pilot journeys include correct independent responses, meaningful support and correction, worked-step revisits, saved draft and review, and exact return to the original Build Understanding question. Existing flashcards, Skills Practice, NEA journeys and reduced-motion reproduction controls are included in regression coverage.
- Browser checks cover keyboard focus, touch, narrow and desktop widths, larger text, simulated 200% zoom and responsive layout. The focused axe scans covered the worked screening table and the written-review view. The pull request records the cross-browser release checks.
- Pupil trials, physical-device testing and specialist screen-reader sessions remain outstanding. Browser tests establish that learners can complete and recover from each journey. Classroom use is needed to evaluate what pupils can explain or apply afterwards.
