# Stretch icon options for teacher review

No option is selected. The three monochrome SVGs are proposals only:

- **A**: paired rectangular plates and a segmented bend.
- **B**: broad rectangular plates and a deep curved bar.
- **C**: rounded plates and a shallower curved bar.

The comparison images show each SVG injected beside the unaltered activity title in the actual GCSE Focused Writing link and Human Biology case card, captured from the running site at a device scale factor of 1. Columns use 16, 20 and 24 CSS-pixel icon boxes; the images are pasted into the sheets at their original pixel dimensions. This is a design mockup, not a claim that any option has been approved or applied to the site.
