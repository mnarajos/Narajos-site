# Tabler reference and bent study

The Narajos interface uses small, rounded outline icons; no named icon library was identified in the checked site source. The reference here is [Tabler Icons' barbell](https://github.com/tabler/tabler-icons/blob/main/icons/outline/barbell.svg) (blob `a02d8ee1cc1971ea8aaeaddf9d3b71e413211794`), licensed under MIT; see [LICENSE.txt](LICENSE.txt). The straight version preserves its original geometry; the bent study retains its proportions and plates while changing only the straight middle bar to a curve with a raised centre. The original straight icon at 24 pixels was selected for the site.

[GCSE comparison](gcse-comparison.png) · [Human Biology comparison](ocr-comparison.png). These are unscaled captures of the existing site links with the icons injected at 16, 20 and 24 CSS pixels, device scale factor 1. At these sizes, the bend is extremely subtle due to the short central bar; visual review is needed.
