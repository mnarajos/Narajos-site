## Reproduction pilot

The original model already showed anatomy, follicle growth, LH-triggered ovulation, the gametes' routes, and separate possible fertilisation and implantation. It mainly described each event after a control was pressed. The optional guide now asks pupils to predict before observing, directs attention to a relevant structure or event, then explains it. The six checkpoints cover follicle development, ovulation, transport, fertilisation, early development and implantation. Pupils can select an earlier checkpoint, read its explanation, read the full written sequence or explore freely. Either fertilisation branch can lead to independent practice. Pause, resume, replay, reset, diagram zoom and existing anatomy controls are retained.

- **F175 before and after.** The original independent task asked what must happen before implantation, largely repeating the demonstrated sequence. The revised task says fertilisation and transport succeeded but the endometrium is unsuitable. The learner must explain which early events can still occur and why attachment can fail. A separate independent question asks about normal ovulation with impaired fimbrial pickup. A mistake about release opens the stage that distinguishes ovulation from uptake into the oviduct.
- **F177 before and after.** The original model named several controlled-trial features together. The revised model shows 15 of 24 people improving with a fictional medicine and 11 of 24 in a comparison group. It explains why people can improve without treatment, what random allocation changes and why the assessor is blinded. The new written case requires applying that distinction to an assessor who knows the allocation.

The F175 knowledge set retains its anatomy, hormone matching, chronological ordering, and written practice. One new fimbrial transfer item brings it to 14 questions and the fixed and rotating bank to 562. The LH question now distinguishes an already mature follicle from the signal that triggers release. The oviduct diagram has feedback specific to the structure chosen.

## Learning paths and assessment integrity

The existing F175 Knowledge Practice menu opens the guided model. Feedback links go to the relevant checkpoint for the F175 anatomy, hormone, transport or development questions. Selected questions in other NEA units open the relevant worked teaching step. The contextual return restores the same question and feedback. Skills Practice teaches the underlying methods and Build Understanding continues to serve the examined units. The revised guided lessons use the existing catch-up renderer and detailed written self-review. Revised prompts have versioned local records so drafts from different questions are not treated as responses to the new prompt.

Using the simulation or revealing a stage explanation records no assessment outcome. The existing question engine keeps independent, supported, corrected, revealed and self-reviewed outcomes distinct. F172–F177 use fictional examples and general biological mechanisms. They offer no assignment production, individual coursework marking or coursework submission.
