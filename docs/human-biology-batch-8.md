# Human Biology Batch 8

## Baseline audit

The application was checked against the Human Biology files on GitHub main at `47ac529`. Batch 7 was merged in PR 57. Its browser and site workflows completed successfully.

The Catch-up catalogue had 62 routes across all eight units. The F170 question and flashcard bank covered 28 sections. The challenge engine already provided question families, staged learning sequences, clinical cases, hints, misconception messages, written-answer self-review, and separate supported and independent results. Skills Practice already generated variants for 14 methods. The existing tissue photos, red-cell scale-bar activity, circulation models, reflex sequence, and reproduction simulation were retained as starting points.

## Specification reconciliation

- F170 3.3.1 explicitly includes recognising uterus, ovarian tissue and testes in photomicrographs. Detailed menstrual-cycle content is excluded from 3.3.1. The F170 hormonal pathway belongs with 3.3.2, with extended cycle context clearly identified where given.
- F170 4.1.2 already explains the corrected term for athlete's foot, tinea pedis, and distinguishes the infection from the causative fungi.
- F175's corrected P1 reference is **3.4 Reproductive health plan**. This is an assessment-reference correction. The app provides general reproduction knowledge and original independent exercises. The F175 assessment guidance and task are outside the teaching materials.
- F170 and F171 are externally assessed. F172–F177 use original general knowledge for NEA units.
