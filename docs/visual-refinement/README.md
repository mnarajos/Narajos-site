# Narajos visual review for PR #86

These are matched Chromium captures at 390 × 844 and 1280 × 850 CSS pixels. Each comparison shows the published website without PR #86, the previous PR at commit `1f7a077`, and the revised PR. Mobile captures are arranged left to right. Desktop captures are stacked in the same order so each page can be read at its original width. All three use the same route and activity state. Figure and practice captures scroll to the named section.

## What changed in the rendered pages

- **A-level Biology.** Sans-serif titles and a teal-tinted three-row paper list give the homepage a clear focal point. Paper names stand out from their descriptions. Topic rows keep their individually coloured labels and accents on neutral surfaces.
- **Human Biology.** Solid teal and blue tiles bring the two examined units forward, while knowledge-support units stay in quieter text rows. The F170 worked micrograph, caption and reasoning share one lightly tinted section.
- **GCSE Combined Science.** Green, purple and blue distinguish the compact subject rows. The method and independent question stay neutral, with a blue-tinted worked example when modelled reasoning is shown.
- **Learning flow.** The captures show the existing navigation and controls, with text labels accompanying the colour cues. Scientific evidence and captions remain visible in context, and each practice state retains its existing Check action.
