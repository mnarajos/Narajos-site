# Narajos visual refinement review

Each pair shows the same route and activity state in Chromium. The left pane was captured on the published Narajos.com site and the right pane from this branch served locally. The viewports are 320 × 740, 390 × 844 and 1280 × 850 CSS pixels. The figure and feedback examples scroll to the relevant section. Written answers are synthetic. The comparison images retain the full viewport for each pane.

## What the rendered pages showed

| Criterion | Assessment |
| --- | --- |
| Clarity | The A-level header fits on one row at both phone widths. The compact paper and unit choices still lead the homepages. The first A-level independent question and its evidence enter view earlier on mobile. |
| Hierarchy | Serif titles anchor pages and topics. The question remains in the sans-serif reading face. The stimulus rail, worked reasoning, subdued topic finder and narrower figure captions distinguish supporting material. |
| Coherence | AQA Biology retains teal, F170 and F171 use teal and blue, and GCSE retains green, purple and blue. Worked and guided stages use blue and purple where stages appear. Text labels and selection affordances accompany the colour cues. |
| Visual quality | Rules, aligned gutters and smaller corners bring the pages together. The F170 micrograph and first reasoning step sit alongside each other on desktop and stack on phones. The GCSE method table keeps its reagent and result columns and uses a light header tint. |
| Cognitive load | Paper selection, inline questions, written self-review, optional support and the existing progression controls use the same routes and controls. Long questions and worked evidence can extend below the fold at 320 px. |
