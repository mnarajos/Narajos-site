# Batch 17 editorial register

Baseline is main at `a053bff4c9304d5e1d5fc4e4b39c46fa3191d24d`, the merge of Batch 16. The live A-level entry page matched the GitHub blob. The [Batch 7 report](alevel-batch-7-report.md) and [Batch 9 report](alevel-batch-9-report.md) describe the ten existing teaching families, 52 original reasoning tasks and 56 drawing variants. Their stepped explanations, drawings, targeted retries and saved outcomes are the starting point. The topic and paper routes already offer practicals, evidence lessons, synoptic prompts and essay planning. Maths Skills already provides worked and adaptive practice in units, dilution, rates, mitotic index, calibration-related calculations, uncertainty, logarithms and statistical-test selection.
