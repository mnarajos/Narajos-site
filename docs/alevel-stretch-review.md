The existing `tier: "H"` metadata and “Core + Stretch” setting are also insufficient evidence of the new definition: sampled H items include isomer recall and routine protein-structure matching as well as application. Maths Skills uses “Stretch” as a procedural ladder level. None should be marked automatically.

Paper 1 and the rest of the A-level topic bank have not been comprehensively reviewed here. The absence of verified markers is a review limitation, not evidence that ordinary practice lacks challenge.

## Further review: Paper 3 topic lessons

The existing setting provides a group-level opt-out: `tierOK` excludes `H` questions in Core, while Core + Stretch includes them. Core + Stretch is the default and the selected questions are then queued in the lesson, with no individual skip. These reviewed examples are candidates for an optional classification if group-level choice is accepted; the individual questions have no stable authored IDs, and adding a classification must not change the existing progress keys.
