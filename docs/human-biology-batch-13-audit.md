# Batch 13 audit

## B13-01 · Guided NEA teaching on main after Batch 12

The Batch 10–12 changes are merged in PRs #61–63, with successful site and browser checks. This audit uses the merged Batch 12 baseline, the Batch 8, 11 and 12 reports, and the [OCR Cambridge Advanced National in Human Biology specification, Version 8](https://www.ocr.org.uk/Images/697578-specification-cambridge-advanced-national-in-human-biology.pdf). The 21 guided NEA lessons use the shared teaching renderer and link to area practice. All use general concepts and unrelated examples rather than live assignments. Reading load is generally manageable. A rating describes the lesson's stated objective, with statement-by-statement coverage reserved for Batch 14.

| Route | Rating | Audit evidence and decision |
| --- | --- | --- |
| F172 a1 | B | Useful DNA prerequisite, division sequence and misconception feedback. Guided naming and gamete copy count do not show pupils how to trace a replicated homologous pair. Strengthen the distinction visually. |
| F172 a2 | B | Clear gamete setup, worked grid and conditional denominator. Guided practice changes the cross but drops the denominator decision, and independent practice returns to the worked cross. Use a new cross that requires both decisions. |
| F172 a3 | A | The worked limited-scope test teaches what detection establishes. Guided uncertainty and independent family reasoning apply that distinction. |
| F172 a4 | A | Expression is modelled as the intermediate step between treating cells and changing tissue function. Guiding and independent tasks distinguish delivery, expression and their limits. |
| F173 a2 | B | Images, prerequisite and skill links are useful. The existing transfer identifies a resizing invariant without choosing an image or using the bar. Add evidence-based selection and measurement. |
| F173 a3 | B | The table and worked Rf example teach a useful method. Guided practice switches to a positive control and independent practice calculates Rf without interpreting a match. Retain for Batch 14 refinement. |
| F174 a1 | A | The same-energy comparison teaches a meaningful distinction. The protein prompt and iron-to-oxygen explanation assess application. |
| F174 a3 | B | The digestion-to-storage path is present. Guided work isolates absorption, but independent work compares enzyme and insulin definitions. Use a new fault in the causal pathway. |
| F174 a4 | B | BMI and hydration explanations are proportionate. Some distractors are implausible and the independent task relies on selecting the only intake measure. Lower priority. |
| F175 a1 | B | Anatomy, conditional events and written review already exist. The model is descriptive, and independent reasoning largely repeats the worked chronology. Pilot prediction, observation and fresh causal transfer. |
| F175 a2 | A | The exchange model distinguishes maternal and fetal circulation, then changes surface area and independently changes diffusion distance. |
| F175 a3 | A | The worked example identifies the disrupted fertility step. The independent motility case applies the same causal reasoning at a different step. |
| F175 a4 | A | Guided ICSI and independent embryo-transfer reasoning distinguish mechanisms and events with specific feedback. |
| F176 a1 | B | The illustrated reflex is a useful reference. Coordination and peripheral route checks are largely recognition. Lower priority. |
| F176 a2 | B | Keep the accurate stepwise synapse model and calcium checkpoint. Make the difference between losing inhibition and gaining excitation visible and vary the independent pathway. |
| F176 a3 | A | The reflex model supplies a clear prerequisite for distinguishing nociception and pain. Transfer considers similar input with different experiences. |
| F176 a4 | A | The fictional scan connects structure and function, acknowledges other explanations and transfers to sensory and motor pathways. |
| F176 a5 | B | The modality explanations are clear. Independent EEG choice closely repeats the worked comparison and could later use a new evidence requirement. |
| F177 a1 | A | The receptor model introduces activation and blockade. Independent reversal of the receptor's effect requires causal transfer. |
| F177 a2 | B | The contrast between observation and a trial is sound. Model randomisation and blinding separately and ask students to interpret a new comparison with one safeguard missing. |
| F177 a3 | A | Sample and follow-up limitations are modelled separately, with independent generalisability reasoning and a link to Skills Practice. |

No guided objective warranted a C rating. The F173 area 1, 4 and 5, F174 area 2 and F177 area 4 routes were also checked as recaps. They do not establish instructional coverage of biomedical roles, practical design/data interpretation, diet-related disorders or research planning. Skills Practice and general evidence examples are already available, and assessed planning remains with the centre. Batch 14 should establish which general concepts warrant further teaching.
