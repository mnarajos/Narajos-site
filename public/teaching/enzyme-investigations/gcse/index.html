Did you describe denaturation and link the change in the active site to fewer enzyme–substrate complexes?

A very high temperature lowers enzyme activity because it denatures the enzyme. The active site changes shape and fewer substrates can bind. Fewer enzyme–substrate complexes form, so the reaction slows.
