A-level · Test for saturation

Start from standard conditions before each trial. Keep enzyme concentration, temperature and pH constant. Try starting substrate concentrations 5, 20 and 40. Compare the peak modelled rates; these capture rates before much substrate has been used up.

Open the A-level model task

After the model. Sketch initial rate against starting substrate concentration. Explain the flattening and predict how doubling enzyme concentration changes the plateau.

Compare with the key ideas

The initial-rate curve rises and approaches a plateau as active sites increasingly become occupied. Extra substrate then has less effect on the rate. More enzyme supplies more active sites and raises the maximum rate. The model’s rate-over-time plot is a different graph: you use a rate from each trial to construct the substrate-concentration plot.
